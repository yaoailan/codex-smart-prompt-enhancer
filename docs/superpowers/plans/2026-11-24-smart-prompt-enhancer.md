# Codex 智能提示词增强器实施计划

> 执行要求：逐项完成并记录验证证据；发布前不得跳过测试、敏感信息扫描和公开访问检查。

## 任务 1：建立技能主体

**文件**

- `SKILL.md`
- `agents/openai.yaml`

**步骤**

1. 按 skill-creator 规范编写技能 frontmatter、适用场景和触发条件。
2. 写入智能路由规则：预览增强任务，直接处理简单任务和控制语句。
3. 规定预览模板、必须预览的分类、禁止扩大授权。
4. 写入开关命令行为。
5. 生成与技能一致的 `agents/openai.yaml`。

**验证**

- 技能名、说明和界面提示一致。
- `SKILL.md` 没有占位符或与设计冲突的规则。

## 任务 2：实现状态管理

**文件**

- `scripts/skill-state.ps1`
- `scripts/skill-state.sh`
- `state.json`（仅本机运行时生成，不提交）
- `.gitignore`

**步骤**

1. 实现 `get`、`on`、`off` 命令。
2. 默认开启；损坏或缺失时恢复为开启。
3. 使用临时文件加原子替换，避免中途失败损坏状态。
4. 为两个平台脚本提供一致的输出。

**验证**

- 默认开启。
- 关闭后读取为关闭。
- 重新开启后读取为开启。
- 非法命令返回非零且不改变状态。

## 任务 3：实现跨平台安装

**文件**

- `scripts/install.ps1`
- `scripts/install.sh`

**步骤**

1. 解析 `CODEX_HOME`，缺省为各平台标准目录。
2. 安装到 `skills/prompt-enhance`。
3. 复制技能文件，保留已有 `state.json`。
4. 不删除目录内无关文件，不修改其他技能。
5. 输出安装位置和启用状态。

**验证**

- 在临时 `CODEX_HOME` 中干净安装成功。
- 已有状态文件在重装后保持不变。
- 重装更新技能正文。

## 任务 4：测试

**文件**

- `tests/test-state.ps1`
- `tests/test-install.ps1`
- `tests/test-state.sh`
- `tests/test-install.sh`

**步骤**

1. 使用系统临时目录，不触碰真实技能状态。
2. 测试默认、关闭、开启、非法输入和损坏状态恢复。
3. 测试安装目标、状态保留和重复安装。
4. 正向与负向用例均返回预期结果。

**验证**

- Windows 脚本全部通过。
- Bash 脚本通过语法检查；系统有 Bash 时运行全部用例。

## 任务 5：文档与许可证

**文件**

- `README.md`
- `LICENSE`
- `PRIVACY.md`

**步骤**

1. README 用中文说明功能、安装、开关、使用示例、验证与卸载。
2. 明确这是技能级增强，不是 Codex 二进制补丁。

**验证**

## 任务 6：本地安装与全局规则

**步骤**

1. 运行 `scripts/install.ps1` 安装到 `$CODEX_HOME/skills/prompt-enhance`。
2. 运行官方 `quick_validate.py` 校验。
3. 在状态脚本中验证默认开启。
4. 备份 `$CODEX_HOME/AGENTS.md`。
5. 保留原文，仅在末尾追加“智能提示词增强默认触发”规则。
6. 输出备份路径和新增规则范围。

**验证**

- 技能校验通过。
- `AGENTS.md` 包含原有知识库和 Agnes 规则。
- 新增规则明确“默认启用、预览确认、简单请求直答”。
